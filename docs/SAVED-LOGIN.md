# 安全记住密码

登录时默认不勾选。仅个人设备建议开启；勾选并登录成功后保存，下次启动通过共享 `useAccountAuth` / store 重新认证，并非跳过服务端认证或永久登录。

| 环境 | 保存方式 |
| --- | --- |
| Windows 桌面 | Windows 凭据管理器（沿用现有实现） |
| macOS 桌面 | 系统钥匙串，`security-framework` 3.7.0 调用系统 Security API |
| Android 原生 APK | 自有 `saved-login` Tauri 插件；Keystore 非导出 AES 密钥，AES-256-GCM 随机 IV + AAD；密文原子写入应用 `noBackupFilesDir` |
| 手机/电脑浏览器、APK 浏览器预览、Linux 桌面 | 应用内记住密码不可用；不回退到明文文件、localStorage、IndexedDB 或自制固定密钥加密。浏览器可使用系统密码管理器 |

本仓库没有 iOS 原生工程，此功能不代表新增 iOS 安装包。

## 行为与失败处理

- 账号、密码和服务器来源一起保存；服务器来源不一致时停止自动登录，要求重新输入，不向另一台服务器发送旧密码。
- 未勾选登录、取消勾选、主动退出登录会清除保存项；密码认证明确失败也清除旧项。网络失败不会被当作密码错误。
- 写入失败仍保留已经成功的登录会话，提示下次手动登录；读取失败提示手动登录。清除失败不显示“已清除”或假退出成功，需重试。
- Mac 首次使用或应用签名改变时，系统可能要求钥匙串授权；拒绝或锁定时不回退到不安全存储。只操作本应用固定 service/account，不读取其他钥匙串项。
- Android 插件仅向本地 `main` 窗口开放四个凭据命令，不启用桌面 IPC；串行后台线程读写，保存/读取均校验字段、服务器和长度。密文损坏或密钥失效会清除不可恢复项并返回读取失败，需手动登录重新保存。
- Android 卸载、清除应用数据或 Debug 签名变化导致必须卸载时，不保留密码；不迁移密钥、备份密文或写日志。Keystore 硬件保护能力由设备决定，不承诺所有设备都使用 StrongBox。
- 安全存储保护静态数据，不代表能防止已被攻陷的应用进程、系统或设备所有者读取运行中的登录信息。

## 构建与验证

修改后需重新构建 Mac 安装包和 Android APK；只刷新网页不会增加原生能力。无数据库迁移或服务端接口变化。

回归：`npm run test:apk` 覆盖两端认证选项/恢复/取消、原生命令路由、浏览器禁用、保存失败、认证失败清除及退出登录。`npm run typecheck`、`npm run build`、`npm run build:apk` 分别检查类型与双端前端产物；Rust 检查不等同于 Kotlin 编译。

Windows 开发机无法完成 Mac 钥匙串与 Android Keystore 实机验收。安装包验收需分别检查：默认不勾选、成功保存后重启自动认证、取消与退出后重启不恢复、错误密码清除、服务器更换阻止自动登录、拒绝/锁定/失效安全存储提示、卸载清理。测试使用专用测试账号，不打印或提交密码；普通自动化回归不访问真实用户的安全存储。
