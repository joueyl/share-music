# QQ 音乐音源

## 随同频服务端运行（默认）

服务端已将 `@yakult-green-tea/qq-music-api@3.3.5` 固定为生产依赖；不再要求单独安装或启动另一个服务。首次访问 QQ 功能时自动启动已安装包，随同频服务端关闭，启动失败可再次请求重试。

```bash
# 仓库根目录，首次安装或升级依赖
npm ci
npm run build -w @music-share/server
npm run start -w @music-share/server
```

开发时可用 `npm run dev:server`。只需按原有要求配置同频数据库和管理员鉴权，不需配置 `QQ_MUSIC_API_URL` 或另开 3200 端口。不要将 Cookie/token 写进环境配置。

打开 `/loginServe`，选择 QQ 音乐和可用扫码 App，获取真实二维码并确认。公网管理继续使用 `NETEASE_ADMIN_TOKEN`（Basic 用户名 admin）和 `NETEASE_LOGIN_ORIGIN`，不改变普通用户的登录方式。

### 隔离与持久化

- QQ 包运行在服务端 worker，不在客户端执行。因上游根入口导入时会自动监听，适配器使用 3.3.5 的非监听模式，再将公开 Koa callback 绑定到 `127.0.0.1` 随机端口；该模式只影响监听、日志和 Explorer/更新检查，歌曲及扫码仍请求真实上游，不是模拟接口。不会更改同频主进程的 NODE_ENV/PORT，不暴露上游通用代理或 Explorer。
- QQ 包输出单独隔离，避免凭据进入主服务日志；客户端仍只访问同频鉴权接口。上游接口变更需重新验证，不能随意去掉固定版本。
- 默认状态目录为服务端工作目录下 `.qq-music/`，可用 `QQ_MUSIC_STATE_DIR` 指定固定的可写私有目录。保存设备身份和加密会话文件；加密密钥首次自动生成并保存在同频数据库 settings，不输出到页面/日志，不复用用户密码或项目 TOKEN_SECRET。
- 数据库与状态目录需一起持久化和受控备份；只保留其中一个不能保证登录可恢复。多实例不可共用同一个状态目录。Docker 镜像默认使用 `/data/qq-music`，现有 compose 的 `/data` 命名卷负责保留。
- QQ 和网易云会话独立；失败、过期或被替换的扫码不覆盖已保存会话。目录不可写、网络受限或包缺失会明确失败，不返回假的成功状态。

## 可选：使用已有外部服务

如果已有按 [上游文档](https://github.com/yakult-green-tea/qq-music-api/blob/main/docs/README.md) 部署的可信 QQ Music API，可设置 `QQ_MUSIC_API_URL=http://127.0.0.1:3200` 并重启同频；此时不启动内置 worker。地址不能包含账号、密码、查询参数或 fragment，跨主机使用 HTTPS，限制上游仅可信内网访问。外部服务自行配置稳定的 `QQ_SESSION_SECRET` 和 `QQ_AUTH_SESSION_PATH` 持久化文件，使用 stored 模式。清空/留空地址即可恢复内置模式。

## 范围与限制

- 支持 QQ 歌曲 MID 搜索、入队、128K MP3 完整播放链接、普通 LRC/翻译歌词、封面、音乐库复用与续链。
- 不提供 QQ 歌单导入、相似推荐或更高音质；网易云功能不变。VIP、版权、地区、登录过期或仅试听的歌曲可能无法导入，不提供绕过。
- 上游 `/getMusicPlay/:mid?quality=128` 没有 MD5。同频在首次导入/续链时有界读取音频计算 MD5 与实际大小，不持久化文件；可能增加服务端带宽与等待时间。保留 100 MiB/60 秒限制、两项导入并发限制、房间权限及幂等保护。客户端仍校验完整字节后播放，不用虚构哈希替代校验。
- 音频只允许 HTTPS 的单层 `*.stream.qqmusic.qq.com`（保留网易云白名单）；QQ 封面只新增 `y.gtimg.cn`。上游若改变 CDN 或响应格式会明确失败，不能通过开放任意 URL 解决。
- 需同步更新服务端、Web 和桌面客户端并重建桌面安装包，旧版客户端未声明 QQ CDN/元数据支持。qqId 存入已有 track JSON，不需要数据库结构迁移。

接口见 [API.md](API.md) 与 [openapi.json](openapi.json)。隔离测试使用模拟 HTTP 响应，不代表真实 QQ 扫码、VIP 授权或 WebView2 音频已联调验收。


## 搜索稳定性与错误

歌曲搜索使用公开匿名目录，不携带服务端播放会话，避免上游登录态与匿名搜索模式差异影响公开搜索；播放取链仍使用已保存 QQ 会话并保留完整权限校验。相同关键词和页码的并发请求合并，成功结果缓存 15 秒（最多 64 项），失败不缓存，不用空列表冒充失败。每用户限流仍在缓存前执行。

仅网络故障、可重试的 502/503/504 自动重试一次，两次请求共享 20 秒总网络预算；上游明确不可重试、鉴权失败或 429 不重试。项目参数错误仍为 400，QQ 上游不可用/响应异常为 502，上游频率限制为 429，QQ 管理登录失效为 503（不是项目用户 token 失效，不触发项目退出登录）。最终失败日志只包含固定错误码和可用的上游数字状态码，不记录关键词、Cookie、会话、URL 或上游原文。

QQ 联想已接入真实 `/search/suggest`，复用 300ms 防抖、取消与键盘选择。舞台封面通过受限字节下载转为本地 Blob 后绘制，避免 QQ CDN 无 CORS 导致贴图缺失；切歌、失败和卸载不会保留上一首封面。Web 需同步升级服务端图片接口，桌面需重建客户端。
