# AI 设计规范 · 同频 TONE

基线：当前 1.0.0 实现；整理日期：2026-10-30。面向 AI 与人工开发者，记录项目已有设计和用户确认的交互，不要求重新设计产品。

## 1. 设计依据与维护

- 原始设计为 Brilliant `brilliant-cloud://witty-jaguar/share-music`，页面映射见 [设计对照](BRILLIANT-WEBVIEW2.md)。当前代码中确认过的自适应和交互也是基准，不能为套回静态画板而回退。
- 按“本次明确需求 → 当前已确认的设计与行为 → 本规范和实际组件 → 历史示例”核对；有冲突时说明差异，不编造设计意图。
- 未提供独立设计稿的页面复用既有视觉系统，不宣称像素级还原。设计稿的示意数据不能直接变成产品数据。
- 改变规则时同步更新规范、说明和测试。应用版本、接口版本和设计基线不是同一概念，不因修改本文自动升版。

## 2. 视觉基础

| 项目 | 当前基准 | 使用原则 |
|---|---|---|
| 主色 | `--accent: #4f80db` | 主要操作、选中、当前歌词和播放状态；主按钮悬停复用 `#4272c9` |
| 正文 | `#283448` | 正文与标题，不降低到难以阅读的灰度 |
| 次要文字 | `--muted: #798394` | 歌手、描述、说明；错误不能只靠颜色表达 |
| 边框 | `--border: #e1e7ee` | 浅色细边框，不使用突兀的暗色粗边框 |
| 背景 | 125° 渐变 `#ddeeff → #f2f1ed（60%）→ #fff2df` | 蓝到奶油色背景，不擅自切换深色或高饱和主题 |
| 表面 | 白色或半透明白，复用 `--surface` | 卡片有层次、阴影轻，不堆叠厚重玻璃效果 |
| 字体 | Microsoft YaHei、Segoe UI、sans-serif | 复用字体栈，不额外加载在线字体 |
| 图标 | lucide-vue-next | 保持线性风格，不混用另一套图标或用 emoji 替代控件 |
| 插画与封面 | 已导出的 SVG / PNG、AlbumArt 和占位图 | 优先复用，不重复下载或任意替换品牌插画 |

- 常见正文 12–14px、辅助信息约 10–12px，歌词与标题使用各自层级。先减少无意义留白和折叠说明，再调整布局，不为塞入固定画布而盲目缩小字体。
- 间距复用 4、6、8、10、12、16、20、24px；控件/气泡圆角约 10–14px，卡片约 18–26px，胶囊按钮用现有样式。数值是组件基准，不是所有位置必须套用的固定值。
- 不把所有按钮都做成主色，不把所有文字放大为营销标题，不任意改变产品标识、包名或应用 identifier。

## 3. 自适应布局与滚动

1. 页面优先 flex，正确设置 `min-width: 0`、`min-height: 0`、内容区 `flex: 1`。适合多列内容的排列可保留 grid，不为统一形式重写所有布局。
2. 桌面可容纳时尽量一屏展示框架，列表消费剩余高度。标题、工具栏和底部操作不参与挤压；封面、按钮不能被压扁。
3. 当前桌面适配区间：宽度大于 900px 且高度至少 640px。导航/播放器高度通过已有变量变化，不重复硬编码固定 960px 画布。
4. 桌面顶部导航、底部全局播放器；窄屏使用当前顶部导航与第二行导航，播放器在底部并考虑安全区。
5. 长列表在自身区域滚动并可聚焦。窄屏、极短窗口、长说明和高缩放下保留必要页面滚动，不裁切控件。
6. 禁止用全局 `scrollbar-width: none`、全页 `overflow: hidden` 或整体 `transform: scale()` 修复溢出。弹窗临时背景锁、已有歌词滚动外观是特定用途，不可扩展为全局禁滚动。
7. 长标题/歌名合理省略或换行，提供完整标题或可访问名称。不能把操作按钮推出窗口，底部播放器不能盖住列表末尾。
8. 使用稳定滚动条占位；内容增减、弹窗打开时不能让页面、导航或播放器横向跳动。

## 4. 控件、反馈与可访问性

- 复用原生 button、input、select、details 和现有组件；整卡操作用原生按钮，不用不可聚焦的 div 模拟按钮。
- 图标按钮有中文可访问名称。保留可见焦点、Enter / Space 与键盘选择；触控主要操作和拖动手柄以约 44px 命中区域为目标。
- Loading、空数据、错误、断线、无权限、成功分别反馈。请求成功必须等待真实确认，不在点击后伪装成功。
- 右上角提示复用 notice 自动关闭逻辑：2 秒消失，新文字重新计时，保留手动关闭；表单错误仍要在相关区域可见。
- 下拉框复用浅色圆角、蓝色选中态。新 WebView 可定制面板，旧运行时保留原生降级；不要破坏键盘、移动端和高对比度模式。
- 聊天与队列滚动条：浅蓝灰圆角细条、透明轨道，8px 轨道内通过透明边框形成细滑块，悬停加深、拖动高亮；不在悬停前完全隐藏滚动反馈。
- 短反馈约 140ms、常规转场约 220ms，复用 `--motion-*`，支持减少动态效果。不为动画延迟请求、排序提交或播放同步。

## 5. 逐页行为清单

### 登录与注册

- 独立页头、品牌标识/涟漪与表单卡片；认证页 main 四边内边距为 0，按父视口伸缩，内容区在所有窗口断点的顶部内边距为 0，保留独立页头及窗口操作区，不保留固定卡片/插画最小高度和大块上下留白。品牌展示尺寸受窗口高度约束，涟漪扩散保持在自身展示范围内；常规窗口登录和注册不产生多余滚动，窄屏、极短窗口或高缩放下由认证主区保留必要滚动，表单控件始终可达。不隐藏滚动条或裁切表单来伪装适配。
- 客户端账号使用用户名/密码认证，不添加邮箱登录假能力；密码 10–128 位。记住登录依赖系统凭据实现，不把密码放入浏览器存储。
- 服务端在成功注册及每次密码登录后保存/更新最近登录 IP，不接受客户端上报，不公开于普通用户响应；默认不信任转发头，代理部署需显式配置可信代理。房间创建时独立记录原始创建者并关联用户，另存创建时用户名、显示名和头像快照，房主转移或资料变化不覆盖；历史未知创建者/创建时资料保持空值，不复制密码、Cookie 或 IP 到房间，不新增公开资料接口。
- 保留确认密码、显示密码、连接中和失败反馈；未开放的找回密码明确说明限制。

- 独立的音乐服务端管理页 `/loginServe` 支持切换网易云（二维码、手机号/邮箱密码）与 QQ 音乐（QQ/微信/QQ 音乐扫码，以上游支持为准），沿用管理员鉴权、同源检查和限流；成功只保存对应音源的全局服务端会话，密码不持久化、不返回凭据。失败保留旧凭据，上游安全验证要求改用扫码，不伪造短信或风控验证能力。QQ API 默认由包管理器安装到服务端并在隔离 worker 内运行，首次使用启动、服务关闭终止，仅监听本机随机端口，设备与加密会话持久化；外部 URL 仅为可选覆盖，不要求用户另行部署。管理页沿用浅色渐变、圆角卡片与蓝色操作；方式切换停止旧轮询和过期反馈，提交中防止重复操作。

### 发现房间

- 主视觉、说明和按钮在正常文档流中使用 flex；按钮下方保留内边距，插画不能覆盖文案和点击区域。
- 整张房间卡片可点击或键盘加入。
- 人数、分类、12 位房间码来自实际后端；满房、断线、加入中禁止重复操作。无好友接口时不伪造好友筛选。

### 一起听

- 唱机与 iPod 保留 Three.js 场景、模型和交互，统一使用 postprocessing 后处理管线：RenderPass → ACES Filmic 色调映射 → ULTRA 级 SMAA 抗锯齿，并叠加当前颜色/深度缓冲格式共同支持的最高 MSAA 采样数（不超过渲染器上限，无可用采样数时仅使用 SMAA）。关闭渲染器内置色调映射和默认画布硬件抗锯齿，由后处理缓冲负责 MSAA。非音频优先档保持最高抗锯齿，会增加 GPU 与显存开销；Mac 音频优先策略见下文。显式使用 sRGB 输出，优先半浮点中间缓冲，不支持浮点颜色附件时降级为字节缓冲；曝光仍为唱机 1.12、iPod 1.15。不增加泛光、景深或表面细分，不更改原始模型、直接光源、阴影与屏幕/标签贴图；碟片材质按下方用户确认的缎面反射规则调整。

- 金属材质补充本地生成的中性摄影棚环境反射（RoomEnvironment + PMREM，强度 0.8），使银色唱片、唱臂及 iPod 金属外壳在非高光角度仍可见，不以降低金属度或加自发光代替反射。环境只用于照明/反射，不设为画布背景，不请求外部 HDR；临时烘焙资源立即释放，环境贴图随舞台卸载释放。

- 透明边缘使用预乘 Alpha 管线：ACES 前解除预乘、之后恢复，SMAA 同时过滤预乘颜色与 Alpha，最后解除预乘并进行 sRGB 转换，再恢复预乘交给浏览器合成。零 Alpha 输出零颜色，最终输出禁用二次混合，避免色调映射和色彩转换把半透明边缘抬亮成白描边；不通过削弱光照、改变模型材质或关闭抗锯齿掩盖问题。

- 高画质档的唱机与 iPod 开启 2× 线性超采样：绘制像素比为原生 devicePixelRatio × 2，宽高各翻倍、像素量约为原生的 4 倍，再由浏览器缩回舞台显示尺寸；保留 SMAA ULTRA 与最高可用 MSAA，GPU 与显存开销进一步增加。不以固定像素预算降采样，仅 GPU 纹理/渲染缓冲尺寸超限时降低倍率。相机与 CSS 布局不变，中间缓冲和 SMAA 尺寸跟随同一绘制前更新路径，组件卸载时释放后处理资源。

- Three.js 舞台保留透明绘图缓冲，尺寸与像素比变化仅在绘制前合并更新；同尺寸观察事件不重复清屏，零尺寸不丢弃上一帧，拖动窗口后不以超长帧时间推进唱机动画。此策略不改变舞台布局，浏览器验证不等于 Windows 原生拖动已验收。

- 房间顶部控制栏保持透明沉浸效果，不叠加独立底色、毛玻璃或分隔线；保留原有操作按钮、可见焦点与窗口拖动行为。

- 保留房间标题和邀请/设置/离开操作、唱机、歌词、聊天及相似推荐。
- 舞台原状态文案位置保持空白，不渲染准备、同步、等待、失败等状态文字，也不保留动态占位行，避免挤动模型和歌词；音频错误通过已有固定 notice 提示，不把准备提示移到舞台其他位置。歌名不过度放大，优先给歌词和聊天分配剩余空间。
- 舞台展示区（唱机/iPod）与歌词始终保持左右并排，不因小窗口改为上下排列；成员胶囊独占正常流行，不用固定最小歌词宽度挤压模型。窄屏与极短窗口允许房间内容滚动，聊天输入区可滚动到播放器上方；长流光歌词换行并在歌词区滚动，不整体缩放页面。
- 相似推荐使用当前歌曲的 simi_song 返回，最多展示 3 首未入队歌曲，不能把待播列表伪装为推荐。切歌取消旧请求，旧结果不能覆盖新歌。
- 推荐点击只入队，不自动打断播放；无来源 ID、空推荐、旧服务端或上游失败均显示真实状态。

### 聊天

- 桌面客户端只对当前房间其他成员的新普通消息请求原生通知、指定提示音与系统注意提醒，不对历史、自发、操作记录、重复或已过期消息提醒。提示音作为固定 PCM WAV 打包，经独立 Web Audio 音效播放，不复用/改变音乐音量、进度或创建第二个音乐 Audio；点击/键盘操作解锁音频，加载失败、音频未解锁及通知请求失败如实反馈。窗口聚焦、离房或退出登录清理任务栏注意状态，不强抢焦点；浏览器只保留页内消息提示，勿扰或系统禁用时不绕过限制。

- 窗口宽度不超过 1100px 或高度低于 640px 时，聊天改为默认收起的非模态悬浮面板，收起按钮固定在右上角控制栏下方且不换行，不随舞台内容或窗口连续缩小下移；展开/收起不改变舞台内部布局或尺寸，宽大窗口仍保留右侧聊天列。复用同一个聊天实例保留草稿，支持关闭按钮、Esc 与焦点恢复，背景舞台仍可操作，其他模态弹窗的共享 inert 锁继续生效。收起时只对当前房间其他成员的新普通消息计数，历史、操作记录、自发消息及重复事件不增加角标；展开清零，切房间重置。

- 紧凑气泡：当前内边距上下 7px、左右 10px，消息间距 12px；短消息按内容宽度显示，不无故撑满整行。
- 保留输入法组合输入、Enter 发送、Shift+Enter 换行、失败重试、底部跟随和未读提示。
- 聊天经服务端确认发送成功后，等待输入框解除禁用再自动聚焦，支持 Enter 与按钮发送；不额外滚动页面。发送失败不清空草稿；切房、离房、组件卸载、聊天收起/播放页停用、断线或模态弹窗打开时不抢焦点。
- 操作记录与普通消息混排但有视觉区分，包含操作者、歌曲、时间/目标进度。只显示服务端确认记录，失败、重试和常规进度上报不能重复刷屏。

### 共享播放列表

- 四种房间共享模式：点歌（queue，默认，只有自然播完才删除该歌曲并接下一首；手动跳过/停止不删除）、随机（shuffle，每轮可播放歌曲均播一次才重新随机，跨轮多首时避免首尾连播同曲）、单曲循环（single，播完重播当前曲）、列表循环（loop，按当前列表顺序从上到下循环）。随机新增歌曲加入未播集合，删除和排序不重置本轮；手动点播/上一首允许主动回听，不是自动随机抽取。不可用歌曲暂跳过。
- 模式由服务端决定，列表下拉框选择或桌面播放器模式按钮轮换；使用独立“播放模式修改”权限（permissions.playbackMode），与切歌及播放列表控制分开；支持房间默认及成员允许/禁止/跟随房间，新房间默认开启。沿用 pending/命令锁、版本和幂等检查，收到真实快照后更新，不重置当前进度。旧服务端无 playbackMode 字段时禁用并提示升级。模式持久化，服务重启仍停止播放并重新开始随机轮次；无历史模式字段的房间默认点歌，播完会移除歌曲，升级前须知。

- 列表按钮再次点击收起，歌曲更多菜单点击其他位置（含另一菜单）关闭；沿用共享背景锁、焦点恢复、Esc 和退出动画，仅保留列表开关可操作，其他背景及播放器控件保持 inert。
- 紧凑头尾布局，列表 flex 占剩余高度；桌面当前最大宽度 560px，窄屏占可用宽度。
- 完整队列高亮当前歌曲；排序不能遗漏它或重置播放进度。
- 双击歌曲行播放该曲，沿用房间播放命令与播放权限；当前曲暂停时继续播放，正在播放时不重置进度。单击不播放，手柄和菜单等嵌套控件的双击不触发行播放；断线、同步过渡、排序/拖动、拖动结束后的保护期及未确认操作时禁止触发，保留原有播放按钮供键盘和触屏使用。
- 房主与拥有“播放列表控制”权限的成员可排序，手柄支持鼠标/触摸和边缘自动滚动，保留 Alt+↑↓ 与菜单微调；普通列表区域仍可滚动。
- 松手后通过 reorder 提交完整 ID 顺序；断线、同步过渡、未确认操作时禁用，版本变化/关闭/取消时撤销拖动并清理动画帧。
- “播放列表控制”统一管理添加、删除任意成员的歌曲、排序和清空；沿用协议字段 enqueue，不另设“加入播放列表”权限。清空保留当前歌曲（含暂停），无当前歌曲时全部清空，播放准备期间禁用；新房间默认权限全开，已有房间保留原设置，房主可修改默认和成员覆盖权限。成员权限下拉框及选项不换行。播放、删除仍校验权限和正在使用的歌曲；无历史 API 时不构造假的已播放记录。

### 我的音乐

- 顶部仅保留“网易云歌单／已收藏”两个分类；紧凑工具栏，卡片和歌曲列表占剩余空间并内部滚动。输入栏接受网易云个人主页、歌单、专辑长链或 163cn.tv 分享短链，数字 ID 兼容为歌单。详情默认收起输入栏，通过“更换链接”展开，可返回原主页/收藏列表。
- 页面应用 Brilliant `09 我的音乐 · 简洁高效`：统一带标签的链接入口、跟随当前主题绿色的打开操作，桌面宽窗口三列横向歌单卡片，中等窗口两列、窄屏单列；整卡按钮打开与独立爱心操作不嵌套。详情使用紧凑封面信息区，返回原列表恢复内部滚动位置及原卡片焦点，不更换全局导航、主题或播放器。
- 收藏成功读取且为空时只显示居中的空数据图标、说明和“浏览网易云歌单”入口，不展示链接表单、歌单或加载/错误/权限演示板块。实际收藏加载中、读取失败与成功空数据分别显示；加载中切换到收藏页不重复发起读取，失败重试成功清除旧错误。
- 我的音乐动效复用全局 140ms / 220ms 时长和缓动：分类指示块滑动，链接表单、详情和空态短淡入，歌单卡片有限错峰入场（18ms 步进，上限 126ms）及鼠标轻悬浮，选中数量和服务端确认后的收藏爱心提供短反馈。动效不延迟请求、不创建循环装饰动画、不因选择变化重建歌曲列表；减少动态效果时关闭新增动画/过渡与悬浮位移，分类指示块仍停留在正确选中位置。
- 详情选择区展示“全选已加载”、已选数量与取消选择；加载更多为追加而非独立分页，全选不能误称全选本页或全部上游歌曲。跟随主题强调色的主操作为“加入房间 · N 首”，仅入队不打断播放；保留次级“立即播放”及其独立播放权限。未加入房间、断线、无权限和房间操作处理中给出真实禁用原因；容量与失败重试仍保留原检查和幂等 ID。窄屏也在现有导航和播放器之间滚动，不用固定遮罩覆盖歌曲。
- 歌单/专辑及搜索“添加全部”采用每批最多 50 首的项目 batch 接口（按音源选择网易云/QQ 路由）；后端只对未缓存或接近过期的歌曲，使用内部 Hana `batch` 合并多歌曲详情与播放链接读取，不向浏览器开放任意上游路径。QQ 上游不使用 Hana batch，由服务端顺序复用既有 QQ 元数据接口。保持逐项幂等、顺序入队、在线权限/容量检查；部分成功不回滚，失败项保留勾选和原 requestId；仅显式“立即播放”触发播放，忽略过期账号/房间结果。
- 按 URL 资源路径识别：user/user/home 为主页，playlist 为歌单，album 为专辑；userid/creatorId 只是附加信息，不能把专辑或歌单误当主页。主页分页获取该用户可访问的全部歌单，每批最多 100 页，超大列表保留“加载更多用户歌单”；直接歌单/专辑只打开该资源，不能退回用户其他歌单冒充结果。
- 歌单详情保留歌曲分页，专辑详情展示真实专辑歌曲；详情内多选加入播放列表，沿用权限、容量、幂等 ID、异步旧结果保护及完整音源校验。切换资源重置歌曲/勾选/分页，切账号清理旧列表和异步结果。
- 收藏仅保存在当前同频账号，不改动服务端网易云账号。支持歌单和专辑收藏/取消、已收藏列表及重新打开详情；等待真实服务端确认，不以浏览器历史或假歌单冒充收藏，失败明确提示，最多 200 项。收藏元数据由服务端验证，沿用 settings 持久化，无结构迁移。
- 短链经服务端固定域名/HTTPS/逐跳检查、5 次请求和 10 秒限制安全展开；不请求最终主页、不携带用户认证或网易云 Cookie、不放开任意跳转。保留旧只解析歌单接口以兼容旧客户端，新页面使用分类资源解析接口。
- 保留多选、全选、批量添加、权限、容量和幂等请求。加载更多在列表内，说明默认折叠；失败项可重试，超时不等于操作未发生。

- 详情歌曲沿用独立浅色圆角卡片，不使用表格列头；每卡显示勾选、无描边和深色底的圆角方形封面、歌名、歌手/专辑和真实时长，未知时长显示破折号。新版常规卡片最小高度 68px、封面 44px，窄屏为 66px / 40px；所有窗口均为单列卡片、每首歌独占一行，歌名及歌手/专辑单行省略不换行，保留选中/悬停/键盘焦点反馈和内部滚动。
- 点击歌单/专辑卡片立即进入详情视图，在详情显示加载、失败及重试，不在列表等待详情接口；加载期间可返回，过期结果不得覆盖列表。卡片封面固定方形并靠起始边对齐，文字占用剩余宽度。

## 7. 技术与真实数据边界

- 保持 Tauri 2 + Vue 3 + TypeScript + Pinia + Vue Router，NestJS 后端、shared 协议校验；不为局部样式引入第二套框架。
- 网易云服务端使用 hana-music-api 3.2.0 的公开编程式 SDK，Node.js 24+；在隔离 Worker 内动态加载 ESM，业务参数与执行配置分离，不额外部署 HTTP API。保留数据库全局 Cookie、只读代理白名单、登录过期保护与后台任务队列，SDK 不自动重试副作用请求；不把上游 200 当作统计入账证明。
- 唯一播放器由 bridge / CloudPlayer 控制 HTML Audio，切路由不创建第二个 Audio。Windows 由 WebView2 解码，Rust 提供原有缓存、下载、系统媒体、凭据和更新能力。网易云及 QQ 导入和续链只读取上游链接与文件大小，不下载音频计算 MD5；客户端不计算或比较音频摘要。`contentHash` 仅作稳定缓存/音乐库键，沿用已有键和缓存位置，保留大小检查、100 MiB/60 秒下载限制、原子写入、并发去重及权限校验。搜索切换音源清空旧结果，忽略过期请求；QQ 暂无相似推荐或歌单导入。
- 保留 Blob 清理与大小检查；遇到 403 等链接失效时静默向后端 `refresh=1` 取新链接并重试一次，续链不弹提示，不改队列或播放进度，不无限循环；持续失败仍不伪造 ready。保留 seek/buffered 后 ready、服务端提交和时间轴同步；本地音量不改变其他成员音量。
- Windows 任务栏悬停缩略图复用当前歌曲实际封面（内嵌优先、网络次之），保留原有缩略图控制按钮；暂停保留，切歌、停止、断线与离房清理旧预览，过期异步封面不能覆盖新歌曲。无封面或失败使用浅色唱片占位图；封面仅应用于独立隐藏代理的任务栏小缩略图；悬停大预览与 Alt+Tab 必须显示真实主窗口内容。禁止在真实主窗口强制设置封面位图、禁用 Peek 或使用专辑海报替代窗口；代理不得单独出现在 Alt+Tab，点击/关闭转交主窗口，收起到托盘及时注销。注册或位图失败回退系统真实窗口预览，不虚报已处理。系统不支持自定义缩略图时保留默认窗口预览，不影响播放。
- 使用现有 bridge/store；权限、容量、expectedStateVersion、requestId / commandId 必须保留。异步请求处理取消、卸载、房间/歌曲切换与旧响应。
- 生产使用 MySQL；公共歌曲来源与 room_tracks 快照分离，房间队列写入 room_tracks，不因 UI 变化自动迁移/删除用户数据。
- 依据 [API](API.md)、[协议](PROTOCOL.md)、[音乐来源说明](MUSIC-SEARCH.md)。接口未部署、鉴权失败和上游失败是不同状态，不能一律伪装为空数据。QQ 公开歌曲搜索不携带全局播放会话；同查询合并并短缓存成功结果，临时网络故障仅一次有界重试；播放取链的登录权限保持不变，上游故障不得当作用户参数错误。

音频连续与流畅交互优先于装饰性画质。原生 capabilities 继续上报 platform/arch，但所有 Mac（Intel、Apple Silicon 及未知架构）统一默认音频优先档，不再因 arm64 自动启用高负载档；不根据 MacIntel UA 判断真实 CPU。音频优先档：1.5×原生 devicePixelRatio 超采样、取消额外像素比与像素预算上限（仍受 GPU 纹理/缓冲尺寸限制）、SMAA HIGH、MSAA最高2×（取颜色/深度共同支持且不超过2的采样数，不支持则仅SMAA）、60fps上限（不再限制30fps）、1024阴影，不保留Mac绘图缓冲；不创建实时频谱的 MediaElementAudioSourceNode，音乐仍走唯一 HTML Audio。非 Mac 高画质档保留2×超采样/最高MSAA/SMAA ULTRA，60fps上限。两种模型在页面隐藏/窗口最小化触发 visibilitychange 时暂停 RAF，iPod 同时停止屏幕刷新定时器；恢复时沿用已有时钟重置与视口同步，缓存房间仍需处于激活状态，不能在大厅恢复绘制。iPod 插值按实际帧间隔换算，避免降帧后动画收敛速度变慢；停用生命周期、歌词与房间共享时钟不受 GPU 帧率限制影响。模型、材质、直接光源、曝光、环境反射与 ACES/透明边缘管线不变；性能提升需目标 Mac 实机复测。

Windows 任务栏按钮初始化：主窗口/封面代理的 TaskbarButtonCreated 通知先以独立标记合并保存，再 PostMessage 排队处理；不要在 WndProc 中立即借用运行时刷新，以免 COM 消息重入时丢通知。启动后最多 5 次原生补偿（重试间隔累计 7.75 秒）（250/500/1000/2000/4000ms 间隔），重试早期 COM 构建或按钮安装失败，不依赖房间播放/前端进度；已工作代理不重复注销。异步回调绑定原会话，退出或替换后不得重新创建按钮。未播放时可显示禁用按钮，启用与回调仍受房间/歌曲/代次和权限控制；冷启动、Explorer 重建及托盘恢复需 Windows 实机复测。

服务端网易云账号任务不新增界面或普通用户副作用接口：北京时间每日 08:00 有 MUSIC_U 时并行尝试安卓（type=0）/PC（type=1）/云贝签到，等待三项均结束（含失败/超时）后，才查询并领取已完成 VIP 任务奖励；各任务独立保存当日尝试标记，保留升级去重，单项失败不阻断其他签到；新的歌曲提交播放生效后即以总时长（秒）异步打卡，不等播完，不能把该字段说成实测收听时长。每日任务与打卡不串行占用业务请求，凭据更换、超时、队列上限及去重见 [网易云说明](NETEASE.md#服务端每日任务与播放打卡)。真实奖励/统计必须单独联调验证。
