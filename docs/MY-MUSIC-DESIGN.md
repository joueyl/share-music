## 设计取舍与当前实现

- 延续同频浅色蓝到奶油渐变、半透明圆角卡片与原顶部导航/全局播放器。Brilliant 静态初稿为蓝色主操作，客户端按最新用户要求继承主题绿色 var(--accent)，不再覆盖独立蓝色，按钮、标签、勾选、选中底色及空态图标统一跟随主题；选中歌曲底色减淡 50%（强调色 5%），边框减淡 50%（17.5%）；不新增主题或第二套导航。
- 保留“音乐主页／已收藏”两个主分类；已收藏下分“已收藏的歌单／已收藏的单曲”，歌单类包含原专辑收藏。列表用统一链接输入入口，支持主页、歌单、专辑；Enter 打开，错误就近提示并保留输入。
- 已收藏成功读取且为空时，仅显示居中的爱心图标、“还没有收藏”、简短说明和“浏览网易云歌单”入口；不展示歌单卡片、链接输入区、加载/错误/权限等演示板块。实际加载和错误状态仍需按真实请求分别处理，不能一律冒充空数据。
- 当前歌单采用封面在上的轻量网格：超过 1200px 五列、761–1200px 四列、601–760px 三列、600px 及以下两列；正方形封面不拉伸，标题最多两行、元数据对齐；卡片 hover 不显示描边、白色底板或阴影，保持背景透明，保留轻浮起和键盘焦点提示；整卡打开，爱心独立操作。返回列表恢复内部滚动位置及原卡片焦点，切换分类分别保留滚动位置。
- 详情收起链接输入，通过“更换链接”展开。紧凑封面信息区及单列歌曲卡片优先让出列表空间，不采用表格列头。客户端仍显示实际加载数量、资源 ID 与真实描述，不复制设计示例数据。
- 详情自动读取完整可访问歌单，不显示手动分页/加载更多，读取期间禁止添加；选择文案为“全选歌曲”，独立显示已选数量与取消选择。主操作只加入待播、不打断当前播放，保留次级“立即播放”及其独立权限；沿用容量、幂等 ID、失败保留勾选和异步过期保护。
- 小窗口压缩信息区而不是缩放页面；窄屏操作区与歌曲列表位于全局播放器上方。通过 flex 分配空间与列表内部滚动，极短窗口保留父级滚动回退，不以隐藏滚动条或裁切页面模拟适配。未更改全局导航/播放器布局，页面强调色继承现有主题，不覆盖其他页面的外观设置。
- 加载可返回，失败可重试；未加入房间、断线、无权限、容量不足须分别说明。不得将设计中的连接/成功示例当作真实反馈。
- 图标按钮需要中文可访问名称、可见键盘焦点；Tab、Enter 与减少动态效果支持沿用既有机制。
- 分类指示块使用 220ms 滑动；链接输入区、详情及空态短淡入，歌单卡片按 18ms 步进错峰入场、最多延迟 126ms，鼠标悬浮轻抬升与箭头位移；选中数量和已确认的收藏爱心有短反馈。不等待动画再发请求或变更数据，不引入循环装饰动效；减少动态效果时取消动画、过渡及悬浮位移，保留正确选中位置。

### 我的音乐页面保活

我的音乐使用账号级 KeepAlive 命名宿主，保留分类、收藏子分类、主页/详情、未提交链接、歌曲选择与内部/页面滚动位置；路由往返不重复初始读取。针对脱离 DOM 后浏览器滚动归零的情况，在宿主捕获实际滚动并于激活后恢复，已移除的滚动节点不再持有。账号切换/注销清除缓存，应用刷新或重启不持久化页面状态。最多缓存当前账号一个我的音乐页和一个房间播放页；换房/退房仅淘汰旧房间播放资源，发现页面不保活，保留原路由过渡、布局包裹和唯一 Audio。

保活验证：全仓 651 项测试通过、1 项按配置跳过，类型检查、完整构建及 `git diff --check` 通过。新增真实 KeepAlive 组件回归覆盖详情/勾选/草稿/滚动恢复、收藏子分类、发现页卸载、隐藏房间停用及换房/退出/切账号淘汰和旧异步结果。独立浏览器模拟接口中检查 1024×640 与 390×844 路由往返：DOM 实例不变、119 首选择与链接草稿保留、歌单滚动 520px/380px、窄屏外层滚动 81px 和收藏列表 200px 恢复，未额外请求主页/歌曲，无横向溢出。未验证桌面安装包或真实音频联调。

播放器收藏入口：移除 ≤1250px 时隐藏爱心的旧规则，所有宽度保持 44px 命中区域；中等窗口压缩控件间距，窄屏收紧摘要宽度，不新增第二个收藏按钮或播放器。收藏/取消复用同一单曲状态，读写失败不伪装成功，切歌按实际来源 ID 更新状态；无来源 ID 时禁用，模态期间仍 inert。
