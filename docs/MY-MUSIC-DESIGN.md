## 设计取舍与当前实现

- 延续同频浅色蓝到奶油渐变、半透明圆角卡片与原顶部导航/全局播放器。Brilliant 静态初稿为蓝色主操作，客户端按最新用户要求继承主题绿色 var(--accent)，不再覆盖独立蓝色，按钮、标签、勾选、选中底色及空态图标统一跟随主题；不新增主题或第二套导航。
- 仅保留“网易云歌单／已收藏”两个分类。列表用统一链接输入入口，支持主页、歌单、专辑；Enter 打开，错误就近提示并保留输入。
- 已收藏成功读取且为空时，仅显示居中的爱心图标、“还没有收藏”、简短说明和“浏览网易云歌单”入口；不展示歌单卡片、链接输入区、加载/错误/权限等演示板块。实际加载和错误状态仍需按真实请求分别处理，不能一律冒充空数据。
- 桌面宽窗口歌单采用三列横向卡片，中等窗口两列、窄屏单列，封面和名称优先；整卡打开，爱心独立操作。返回列表恢复内部滚动位置及原卡片焦点，切换分类分别保留滚动位置。
- 详情收起链接输入，通过“更换链接”展开。紧凑封面信息区及单列歌曲卡片优先让出列表空间，不采用表格列头。客户端仍显示实际加载数量、资源 ID 与真实描述，不复制设计示例数据。
- 画板“全选本页”在客户端改为准确的“全选已加载”（原接口加载更多会追加歌曲），独立显示已选数量与取消选择。主操作只加入待播、不打断当前播放，保留次级“立即播放”及其独立权限；沿用容量、幂等 ID、失败保留勾选和异步过期保护。
- 小窗口压缩信息区而不是缩放页面；窄屏操作区与歌曲列表位于全局播放器上方。通过 flex 分配空间与列表内部滚动，极短窗口保留父级滚动回退，不以隐藏滚动条或裁切页面模拟适配。未更改全局导航/播放器布局，页面强调色继承现有主题，不覆盖其他页面的外观设置。
- 加载可返回，失败可重试；未加入房间、断线、无权限、容量不足须分别说明。不得将设计中的连接/成功示例当作真实反馈。
- 图标按钮需要中文可访问名称、可见键盘焦点；Tab、Enter 与减少动态效果支持沿用既有机制。
- 分类指示块使用 220ms 滑动；链接输入区、详情及空态短淡入，歌单卡片按 18ms 步进错峰入场、最多延迟 126ms，鼠标悬浮轻抬升与箭头位移；选中数量和已确认的收藏爱心有短反馈。不等待动画再发请求或变更数据，不引入循环装饰动效；减少动态效果时取消动画、过渡及悬浮位移，保留正确选中位置。

## 验证边界

已通过 Brilliant MCP 创建和读取新画板，导出预览检查设计稿；原设计页未修改。客户端已运行组件回归、类型检查、完整构建和全仓测试。

已在独立浏览器上下文以模拟 API 数据检查 1440×960、1280×720、1024×640、390×844，以及 640×360 的等效 200% 缩放空间；长标题/歌手/专辑、50 首歌曲、18 张歌单、收藏空数据、读取失败、滚动恢复和操作区可达性均作隔离检查，未发现横向溢出或播放器覆盖操作区。返回列表的滚动位置与原按钮焦点已验证。加载中、无房间/断线/无权限/操作处理中、容量、失败重试、幂等及旧响应保护另有组件测试。

本次不修改接口；模拟界面不等于真实网易云联调、真实歌曲播放或桌面安装包验收。真实系统缩放/键盘导航、Windows/macOS 安装包与真实接口仍需复测。

配色与动效补充检查：1440×960 隔离预览确认强调色继承 #5dbb00、卡片最大延迟 126ms、分类指示块过渡 220ms 且均为有限动画；390×844 减少动态效果模式下新增动画数为 0、分类滑块立即停留在已收藏一侧，未发现横向溢出。Brilliant 静态画板本轮未重绘，动态表现以客户端及上述规范为准。
