# 发布验收操作

## 平台与播放

在 Windows 10/11、macOS 13+、Linux 的目标桌面环境分别构建、安装与运行。验证登录、房间、搜索、音乐库、指定歌单导入、歌词、聊天和队列；按 [打包说明](PACKAGING.md) 核对平台运行库、签名及安装产物。

使用有效网易云音源检查 HTML Audio 播放、暂停、进度拖动、音量、频谱和封面。验证首次下载、磁盘缓存命中、缓存损坏、缓存无法写入、哈希不符、文件过大、链接过期与上游失败，错误应明确显示，不冒充播放成功。

Windows 检查任务栏缩略图按钮、系统媒体面板与快捷键，Linux 检查 MPRIS；验证无权限、断线和离房后不能控制。检查关闭窗口进入托盘、恢复窗口、显式退出及托盘初始化失败时的正常关闭。

## 布局与键盘

检查 1024×640、1280×720、1440×960、390×844，以及长文案、空/长列表、加载、失败、断线和高缩放。内容与控件不能被底部播放器遮挡；列表保留内部滚动，短窗口允许必要页面滚动。

弹窗检查 Esc、Tab 循环、关闭后焦点恢复、背景滚动锁和滚动条占位。队列拖动、边缘自动滚动、Alt+↑↓ 及菜单微调仅限房主，版本变化与取消时清理拖动状态。

## 同步与控制

8 台真实设备播放 30 分钟。每秒采样客户端媒体时钟，统计同一服务器时间的最大/最小进度差，保存原始数据与 P50/P95/P99；目标 P95 ≤100ms。另用共同录音或测量设备检查实际声学输出，不能用 UI 进度替代。

测试连续拖动、同时切歌、暂停/恢复及中途加入。准备完成且缓冲到目标位置后才报告 ready，服务端提交后按共享时间轴播放。切换未完成时拒绝重叠操作，冲突后获取新快照并重新确认意图，不自动重放过期命令。

测试离房、房主断开、控制连接断开、重连及服务重启；检查本地播放停止、房主移交、过期响应丢弃、Blob 释放与数据库队列恢复。服务重启后播放停止，成员重新加入。

## 权限、容量与持久化

分别授权和撤销切歌、进度切换及加入列表权限，绕过 UI 直接发送 HTTP / WebSocket 请求，验证服务端仍拒绝越权。检查普通成员覆盖、房主权限、房主排序及幂等重试。

开启至少 3 个房间、总计 24 个控制连接，每房间不得超过 8 人。记录服务器 CPU、RSS、控制往返、音频接口流量与并发下载。注入限速、丢包、抖动和断网，验证真实失败反馈与有界内存，不能承诺未经测量的带宽容量。

使用隔离数据库验证队列/权限成功回执等待落库、写入失败进入保护状态、重启恢复和迁移回滚边界；不要对生产数据库执行破坏性测试。

## 结果归档

保存代码版本、系统与 WebView 版本、音频设备、音源规格、参与者数量、时长、原始时钟数据、流量、CPU/RSS、脱敏异常日志及通过/失败项。失败项修复后重测；模拟界面、隔离测试、真实接口联调和安装包验收分别记录。
