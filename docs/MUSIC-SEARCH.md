# 搜索歌曲并保存音乐直链

当前房间“添加音乐”可切换网易云或 QQ 音乐搜索，选择后服务端取得正常可用的完整 MP3 链接，在 MySQL 中保存 URL、过期时间和稳定歌曲 ID，再加入共享队列。
音频文件不在服务端持久化。网易云和 QQ 导入/续链只取链接、有效期和文件大小等元数据，不下载整首音频计算 MD5。客户端保留大小与边界检查，不计算或比较音频摘要。

接口 `POST /api/rooms/:id/music/netease` 或 `POST /api/rooms/:id/music/qq`（QQ 的 songId 为歌曲 MID），body `{songId,requestId}`，Bearer 鉴权。
成功回执等待数据库写入与入队完成；网络重试复用 requestId，失败不显示“添加成功”。
进房权限、点歌权限和容量在工作前、入队前检查；离房后不返回音频。


有效链接从数据库复用；接近过期时依稳定歌曲 ID 取新链接、保存新的过期时间。无有效上游过期时间则保守按 5 分钟。
客户端下载遇到 403 等失效时，静默通过 `refresh=1` 向后端取新链接并重试一次，不弹续链提示。网页代理遇到 401/403/404/410 同样最多刷新并重试一次，不无限循环。
同一歌曲续链保留已有稳定缓存键，更新链接和大小，不改变队列或播放进度；失效刷新不绕过登录、付费、地区或试听限制。

音乐库使用 `/api/music/uploaded` 查询，通过 `/api/rooms/:id/music/uploaded` 添加歌曲到房间。
按持久化缓存/来源记录复用，包含已移出房间的来源；不再保证不同来源按音频字节去重。旧网易云歌曲可从来源 ID 恢复，无来源 ID 的纯本地旧记录无法自动续链。
`POST /api/music/upload` 接受 JSON `{songId}` 登记链接。

网易云搜索建议、相似推荐和歌单批量导入保持不变；QQ 支持搜索、真实联想、歌词、封面与音乐库复用，暂不支持相似推荐或歌单导入。下载地址只允许 HTTPS `*.music.126.net` 或 `*.stream.qqmusic.qq.com` 的单层子域，每次重定向重新校验，限制 100 MiB / 60 秒。

“我的音乐”使用“网易云歌单／已收藏”两个分类。输入个人主页时分页读取该用户可访问的歌单，输入歌单或专辑时直接打开其详情；album 不因附带 userid 而变为主页，playlist 不因 creatorId 而加载用户所有歌单。详情内可多选加入房间播放列表，更换资源重置歌曲、勾选与分页。歌单和专辑可收藏到当前同频账号，已收藏可重新打开或取消，不修改共享网易云账号的收藏。

同时支持手机分享的 `163cn.tv` 短链接及包含单个链接的分享文案。完整链接和数字 ID 本地解析；短链接经带项目登录鉴权的 `POST /api/music/playlist/resolve` 展开，避免浏览器跨域限制。不携带用户 token 或网易云 Cookie 访问短链；短链请求强制 HTTPS，逐跳校验固定域名、协议、凭据、端口和目标歌单路径，最多 5 次请求、总超时 10 秒，只读取重定向头、不执行网页脚本。长链支持 music.163.com 与 y.music.163.com 的桌面/移动歌单格式。新页面支持主页、歌单、专辑三类目标；其他资源、失效短链、循环和非受信目标均明确失败，不退回无关歌单。旧 /music/playlist/resolve 仍仅接受歌单，新分类解析使用 /music/reference/resolve。此功能需同步更新服务端。
管理员通过 `/loginServe` 选择并登录网易云或 QQ 音乐，两者独立保存会话，不在 .env 填 Cookie。QQ 默认随服务端依赖运行，见 [QQ-MUSIC.md](QQ-MUSIC.md)。HTTPS、来源白名单和权限检查保留。

完整接口和升级说明见 [API.md](API.md)、[MYSQL.md](MYSQL.md)。

## 缓存兼容与升级

需同步更新后端与客户端并重建安装包。`contentHash` 继续使用 32/64 位小写十六进制作为不透明缓存/音乐库键；旧记录键保持不变，网易云新记录可沿用上游提供的合法键、缺失时生成随机键，QQ 新记录生成随机稳定键。此字段不再承诺是音频摘要。

缓存位置、命名、重启/跨房间复用、并发去重和原子写入不变，不清空已有缓存或队列，无数据库结构迁移。截断文件仍按大小拒绝，但等长损坏不再由摘要校验发现。QQ 详情需提供有效 `file.size_128mp3`，不为补齐摘要下载音频。
