# 搜索歌曲并添加到 OSS

房间的“添加音乐”打开搜索弹窗，通过服务端网易云账号搜索，展示歌曲、歌手、专辑和时长，支持分页。点击“添加”后，服务端获取当前账号可用的标准音质 MP3 地址，下载原始字节、计算 SHA-256、上传 OSS 并执行房间入队命令。只有这两步全部成功，HTTP 才返回成功，弹窗显示“已添加”，客户端提示“添加成功”。房间列表仍由 WebSocket 推送同步。

接口：`POST /api/rooms/:id/music/netease`，本项目 Bearer 认证，JSON 为 `{songId, requestId}`（歌曲 ID 字符串、UUID 请求 ID）。客户端不提交外部下载 URL，也不持有网易云或 OSS 凭据。进房权限、添加权限及容量会在下载前、上传前、上传后重新检查。

网络重试复用请求 ID：进程内同一用户同一请求最多执行一次；不同歌曲不能复用请求 ID。成功记录保留一小时，失败后可重试。此记录不跨服务器重启持久化。下载源仅允许网易云音乐 CDN 单层子域 `*.music.126.net`，强制 HTTPS，每次重定向都重新校验，不接受本地地址、认证信息、非标准端口。下载上限 100MB/60秒，同时处理最多两首；OSS 上传沿用现有超时与脱敏错误信息。

仅接收账号正常获得的完整 MP3，不绕过 VIP/付费/地区权限，拒绝试听片段或不可用音源。请自行确保上传和共享音乐的授权。音频帧头解析用于采样率/声道元数据，MP3 的 bits=16 表示播放器解码基准，不代表源音频是无损。暂不支持网易云返回的其他编码。

前置条件：管理员已通过 `/loginServe` 登录，且 OSS 上传权限已恢复。依赖自身的安全告警见 NETEASE.md。Nginx 示例已为新增导入路由设置 240 秒等待；部署时需同步配置。若上传成功后用户离房或权限被撤销，入队失败，不提示成功；可能留下未引用的 OSS 对象，应通过生命周期或后台维护清理。

验证：服务端模拟测试覆盖下载、上传、入队确认、失败重试、权限变化、试听限制、重定向及体积限制。浏览器使用模拟搜索/上传响应验证弹窗、搜索结果、上传中状态和延迟成功提示；未声称已完成真实歌曲到 OSS 的全链路验证。

输入联想：停止输入 300ms 后通过已认证的 search_suggest 接口请求关键词建议，最多显示 8 条；输入法组合输入期间不请求，清空、失焦、关闭和正式搜索时取消等待及过期请求。鼠标点击或上下键选择后按回车可直接搜索，Escape 先关闭联想列表，再按一次关闭弹窗。联想失败不阻止普通搜索。

联想排查更新：输入框显式处理 input/compositionend，中文候选确认后与英文走同一防抖链路；请求失败或服务端未加载 search_suggest 白名单时会在下拉中显示提示，而非静默隐藏。已在隔离内存服务端、真实 API 和浏览器完整认证链路验证“love”和“周杰伦”返回并显示联想。更新后须重启非 watch 服务端，客户端须刷新或重建安装包。

## OSS 去重与文件名

新增 SQLite `music_assets`（目标 Bucket/地域＋SHA-256 → 对象键）和 `music_sources`（目标 Bucket/地域＋网易云歌曲 ID＋音质 → 元数据）索引。网易云歌曲命中索引且 OSS HEAD 确认存在时，不再请求播放地址、下载和上传；不同房间、不同成员或重启服务端后均可复用对象。每次加入列表仍生成独立音轨 ID。新上传的本地文件也按服务端计算的 SHA-256 去重，不信任客户端声明的哈希。

对象路径示例：`music/files/<SHA-256>/晴天 - 周杰伦.mp3`，同名不同内容位于不同哈希目录。网易云使用 song_detail 的真实歌曲名和当前实际支持的 MP3 后缀，本地文件保留用户提供的文件名与后缀。文件名保留中英文和空格，替换斜杠、控制字符等不安全字符并限制长度；相同内容首次上传的文件名会保留，后来改名不会再次上传。

同一服务进程的并发相同歌曲/内容请求合并；先 HEAD 检查，404 才上传，403 或网络失败不会被当成“文件不存在”。PUT 使用禁止覆盖头以防同键竞争（Bucket 版本控制可能影响此头，见官方说明）。数据库记录只在上传成功或确认对象已存在后写入；已上传但入队失败也保留索引，重试可复用。索引随数据库持久化，备份和迁移时务必保留。单进程锁不是跨机器分布式锁。

旧版 `music/<用户UUID>/<对象UUID>` 继续允许播放，不会自动删除、重命名或改写旧对象。旧版未持久化歌曲来源和内容哈希，无法凭随机对象名恢复歌曲映射；没有索引的旧对象需要另行迁移或提供映射才能可靠去重，当前未执行历史扫描/迁移。

新增路径不再带上传者 UUID；服务端入队时校验对象键与内容哈希必须匹配本 Bucket 的已登记资产，防止通过前端任意伪造引用。需要接入点的正常对象读取/HEAD 和写入权限。

网易云新文件名包含真实歌手：`歌曲名 - 歌手名.mp3`，多位歌手以“、”连接并去除重复名字，兼容 ar / artists 字段；缺失真实歌手时拒绝上传，不编造歌手名。已有对象仍按内容索引复用，不因命名格式变更而重复上传。
