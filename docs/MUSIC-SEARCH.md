# 搜索歌曲并保存音乐直链

当前房间“添加音乐”搜索网易云，选择后服务端取得正常可用的完整 MP3 链接，在 MySQL 中保存 URL、过期时间和稳定歌曲 ID，再加入共享队列。
不再上传 OSS、不依赖对象存储配置、不在服务端持久化音频文件。首次导入和取新链接时临时读取音频来计算 SHA-256、大小和音频规格，兼容既有校验缓存；不会把上游 MD5 冒充 SHA-256。

接口 `POST /api/rooms/:id/music/netease`，body `{songId,requestId}`，Bearer 鉴权。
成功回执等待数据库写入与入队完成；网络重试复用 requestId，失败不显示“添加成功”。
进房权限、点歌权限和容量在工作前、入队前检查；离房后不返回音频。

有效链接从数据库复用；接近过期时依稳定歌曲 ID 取新链接、保存新的过期时间。无有效上游过期时间则保守按 5 分钟。
网页下载收到 401/403/404/410 时最多再取链一次；桌面下载失败最多请求 refresh=1 重试一次。
音源发生变化则提示重新添加，不忽略哈希校验；失效刷新不会绕过网易云登录、付费、地区或试听限制。

音乐库沿用 `/api/music/uploaded` 和 `/api/rooms/:id/music/uploaded` 路径以兼容调用方，但不再表示 OSS 上传目录。
按音频内容去重，包含已移出房间的来源记录；旧网易云歌曲可从来源 ID 恢复，只有本地音频且没有来源 ID 的旧记录无法自动获取网络链接。
本地音频云上传已停用；`POST /api/music/upload` 改为 JSON `{songId}` 登记链接，二进制上传返回 410。

搜索建议、歌词、封面、歌单批量导入及请求去重继续使用现有接口。下载地址只允许 HTTPS 网易云音乐 CDN 单层子域，每次重定向重新校验，限制 100 MiB / 60 秒。

“我的音乐”仅导入输入链接/ID 指定的歌单：读取详情后直接展示其歌曲与歌单 ID，分页也始终使用当前歌单 ID。不再调用用户歌单接口，不展示用户其他歌单，不读取或保存“最近导入”记录；更换歌单会清空之前的歌曲、勾选和分页位置。

同时支持手机分享的 `163cn.tv` 短链接及包含单个链接的分享文案。完整链接和数字 ID 本地解析；短链接经带项目登录鉴权的 `POST /api/music/playlist/resolve` 展开，避免浏览器跨域限制。不携带用户 token 或网易云 Cookie 访问短链；短链请求强制 HTTPS，逐跳校验固定域名、协议、凭据、端口和目标歌单路径，最多 5 次请求、总超时 10 秒，只读取重定向头、不执行网页脚本。长链支持 music.163.com 与 y.music.163.com 的桌面/移动歌单格式。非歌单、失效短链、循环和非受信目标均明确失败，不退回用户的其他歌单。此功能需同步更新服务端。
管理员通过 `/loginServe` 登录网易云；不在 .env 填写 Cookie。部署后需同时更新服务端和客户端，桌面新版本仅允许网易云 CDN 下载。

完整接口和升级说明见 [API.md](API.md)、[MYSQL.md](MYSQL.md)。旧 OSS 架构文档仅用于历史排查，不适用于当前版本。
