# 搜索歌曲并保存音乐直链

当前房间“添加音乐”搜索网易云，选择后服务端取得正常可用的完整 MP3 链接，在 MySQL 中保存 URL、过期时间和稳定歌曲 ID，再加入共享队列。
音频文件不在服务端持久化。后端直接保存 `song_url_v1` 返回的 MD5 与大小，导入和续链不下载音频、不计算哈希，也不推测缺失的音频规格。前端对实际音频计算 MD5 并比对大小，通过后才播放；无有效 MD5 或大小时拒绝导入。

接口 `POST /api/rooms/:id/music/netease`，body `{songId,requestId}`，Bearer 鉴权。
成功回执等待数据库写入与入队完成；网络重试复用 requestId，失败不显示“添加成功”。
进房权限、点歌权限和容量在工作前、入队前检查；离房后不返回音频。

有效链接从数据库复用；接近过期时依稳定歌曲 ID 取新链接、保存新的过期时间。无有效上游过期时间则保守按 5 分钟。
客户端下载失败或 MD5/大小不一致时，自动通过 `refresh=1` 强制获取新直链及对应 MD5、大小，再下载校验一次，成功后继续播放；再次失败才显示错误。网页代理收到 401/403/404/410 时也最多刷新并重试一次，不无限循环。
同一歌曲的新直链和新 MD5/大小配套使用，刷新不改变队列或播放进度，不忽略哈希校验；失效刷新不会绕过网易云登录、付费、地区或试听限制。

音乐库使用 `/api/music/uploaded` 查询，通过 `/api/rooms/:id/music/uploaded` 添加歌曲到房间。
按音频内容去重，包含已移出房间的来源记录；旧网易云歌曲可从来源 ID 恢复，只有本地音频且没有来源 ID 的旧记录无法自动获取网络链接。
`POST /api/music/upload` 接受 JSON `{songId}` 登记链接。

搜索建议、歌词、封面、歌单批量导入及请求去重继续使用现有接口。下载地址只允许 HTTPS 网易云音乐 CDN 单层子域，每次重定向重新校验，限制 100 MiB / 60 秒。

“我的音乐”仅导入输入链接/ID 指定的歌单：读取详情后直接展示其歌曲与歌单 ID，分页也始终使用当前歌单 ID。更换歌单会清空之前的歌曲、勾选和分页位置。

同时支持手机分享的 `163cn.tv` 短链接及包含单个链接的分享文案。完整链接和数字 ID 本地解析；短链接经带项目登录鉴权的 `POST /api/music/playlist/resolve` 展开，避免浏览器跨域限制。不携带用户 token 或网易云 Cookie 访问短链；短链请求强制 HTTPS，逐跳校验固定域名、协议、凭据、端口和目标歌单路径，最多 5 次请求、总超时 10 秒，只读取重定向头、不执行网页脚本。长链支持 music.163.com 与 y.music.163.com 的桌面/移动歌单格式。非歌单、失效短链、循环和非受信目标均明确失败，不退回用户的其他歌单。此功能需同步更新服务端。
管理员通过 `/loginServe` 登录网易云；不在 .env 填写 Cookie。部署后需同时更新服务端和客户端，桌面新版本仅允许网易云 CDN 下载。MD5 用于文件一致性比较，不作为安全签名；HTTPS、来源白名单和权限检查继续保留。

完整接口和升级说明见 [API.md](API.md)、[MYSQL.md](MYSQL.md)。

## MD5 校验与升级

后端与客户端必须同步更新，桌面需重新构建安装包。`contentHash` 的 32 位值表示接口 MD5，已有 64 位 SHA-256 仍可读取及作为音乐库引用，但不得将其截断或当作 MD5。新导入会按来源 ID 获取 MD5 元数据并更新公共来源记录；音乐库的内容哈希随之变化，需刷新列表后使用新引用。无需数据库结构迁移，不自动清空队列或缓存。

已有 SHA-256 队列歌曲在请求新链接时自动取得当前 MD5 元数据，无需手动重新添加。按新 MD5 建立独立缓存键，不复用未经 MD5 校验的 SHA-256 缓存文件。客户端保留对已有 SHA-256 字节的只读校验支持。
