# Brilliant 设计与 HTML Audio 播放

## 设计基准

AI 与人工协作统一参考 [AI 设计规范](AI-DESIGN.md) 和根目录 [AGENTS.md](../AGENTS.md)。

Brilliant 项目：brilliant-cloud://witty-jaguar/share-music。
- 01–04 房间与播放器：一起听、发现、创建、队列。
- 05 登录 / 06 注册：用户名与密码认证。
- 07 搜索歌曲：点歌搜索。
- 08 API与播放实现：本次新增的实现范围与后端约束。

实现保留 Vue / Pinia / Router，不引入第二套 UI 框架。tone.css 在现有组件样式及响应式样式之后加载；蓝色 #4F80DB、蓝到奶油渐变、浅色半透明卡片、桌面顶部导航，窄屏使用当前顶部双层导航与底部全局播放器。不存在真实 API 的推荐内容、头像编辑、房主审批、喜欢等不伪装成功。

## 当前 API 对照

- POST /api/login：name/password/register，不采集邮箱。
- GET /api/rooms?keywords=&category=：房间搜索、分类，列表人数来自后端。
- POST /api/rooms：名称、描述、氛围、可见范围。
- GET /api/rooms/resolve/:code：12 位房间码解析后 WebSocket join。
- PUT /api/rooms/:id/settings：完整设置和 expectedStateVersion；冲突提示用户，不无限重试。
- 网易云搜索 / music/uploaded：搜索点歌和共享音乐库，requestId 幂等。
- /music/:trackId 与 refresh=1：桌面下载直链，下载失败只强刷一次。
- /music/:trackId/audio：浏览器 Bearer 鉴权代理；校验长度、SHA-256 后创建 Blob。

## 播放边界

CloudPlayer 唯一控制 HTMLAudioElement。桌面由 WebView2（Windows）解码，不经过 native::Native、FFmpeg 或 SDL。Rust 缓存读取和 HTTPS 下载仅提供校验后的原始字节，HTML Audio 播放同一 Blob；波形分析与内嵌封面基于同一音频。

ready 必须等待目标位置 seek 完成并 buffered；服务器提交后依据共享时间轴播放/暂停/纠偏。退出房间、切歌或过时下载会清理或释放 Blob。本地音量不改变房间音量。Windows 系统媒体按键继续调用房间指令，不创建原生播放器。

不支持系统采集、P2P 直播或运行时转码。旧 native/ 与 Rust 协议模块只为历史源码和兼容测试保留，不参与当前桌面启动及发布构建。真实播放需服务端、在线房间成员与有效网易云音源；测试中的模拟界面不代表真实联调成功。

GlobalPlayer.vue 在发现、房间与我的音乐页面底部持续显示。唯一 HTML Audio 实例仍由 bridge / CloudPlayer 控制，切路由不重新创建音源。本地音量、进度预览、权限和 pending 锁均保留。

发现页主视觉与卡片列表使用正常文档流的 flex 布局：按钮下方保留留白，封面不可被压缩，短窗口使用紧凑间距而非裁切内容。房间卡片本身为原生按钮，点击或按 Enter / Space 加入；移除氛围标签和独立加入按钮。断线、房间已满、正在加入时禁用相应操作，保留状态反馈。

“相似推荐”区域通过当前歌曲网易云 ID 调用后端 `simi_song`，展示最多 3 首未在队列中的推荐歌曲。切歌取消旧请求，普通状态同步不重复加载；无播放、无来源 ID、推荐为空或接口失败时展示真实状态，不使用待播列表充当推荐。点击歌曲只加入队列，不自动切歌，沿用后端权限和幂等请求。收藏与循环能力未提供时禁用，不假装已收藏或改变播放模式。

当前 Brilliant 文件未提供独立“我的音乐”、音乐库、成员权限、更新日志画板；这些界面复用原稿的顶部导航、渐变、卡片、按钮与列表系统，不宣称像素级对应不存在的画板。

原稿插画直接从 Brilliant 导出：登录唱机 / 默认专辑为 SVG；房间唱机与发现页唱片用 PNG 保留渲染器的金属刻纹与效果，避免 SVG 导出丢失描边。没有额外在线字体或图片请求。

弹层共享带引用计数的背景锁，队列切换搜索时不提前解除 inert，也不会在关闭搜索后永久锁住页面。键盘焦点、Esc、Tab 和滚动恢复保持可用。

播放列表压缩头尾留白、移除重复说明与独立当前歌曲卡片，列表 flex 占满剩余空间。拖拽仅操作手柄（支持 Pointer Events 鼠标/触摸），松手后通过既有 `reorder` 命令发送完整歌曲 ID 顺序，不重置当前播放或进度；仅房主可排序，断线、同步过渡和未确认操作期间禁用。房间状态版本变化、关闭抽屉、指针取消时撤销拖拽并停止自动滚动，避免覆盖新队列；服务端仍负责权限和状态版本校验。

页面几何自适应由 `adaptive-layout.css` 负责（其后还加载下拉框样式 selects.css），而不是全局隐藏滚动条。桌面窗口（宽度超过 900px、高度至少 640px）按实际视口分配导航、播放器和主内容空间；舞台、歌词和聊天伸缩，发现房间、歌单和歌曲列表在内部滚动。搜索弹层同样使用可伸缩结果区。登录/注册取消固定 960px 最小高度，短窗口缩减留白和插画尺寸。窄屏、极短窗口、长文案和高缩放保留必要滚动，不裁切控件；新增内部列表可聚焦，支持键盘滚动。
